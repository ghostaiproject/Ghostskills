# Specs
| Output | Size | Notes |
|---|---|---|
| Phone image / wallpaper | 1080x2340 | keep text out of top 120px and bottom 160px |
| Square post | 1080x1080 | |
| Slide | 1920x1080 | ≤6 lines per slide |
| Chart | fits width 1080 | label lines directly, ≤5 colors |

- Fonts: one sans family (Inter, Segoe UI, system-ui); title 64-96px, body ≥32px on phone images.
- Palette: white or near-white bg, dark gray text (#1f2328), one accent; dark mode = invert bg/text, same accent.
- Margins ≥64px on phone images; align to a simple grid.
- Charts: no 3D, no gridline clutter, start bars at 0.
