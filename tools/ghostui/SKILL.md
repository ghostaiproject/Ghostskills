# GhostUI (app + site design; look → ghostfiles)
Learned from Justinmind templates (smart home, weather, food delivery, data viz cards, onboarding) · ghost 2026-11-02

## System
- Flat: no shadows → depth from fills, 1px borders, tinted canvas.
- Canvas tint + white cards: light #F1F2F7 / dark navy #1B2233 with lighter cards.
- One brand accent (indigo #5665E3 or violet #6555FF) + one soft support tint. Data colors only in charts: green #6CC986, indigo #5665E3, amber #F0C774.
- Type: one sans (Poppins / Lato / Roboto); optional serif for headings only. Scale 11·13·16·20·30·35+. Weights 400 + 600 only.
- Radius: cards 10-12, inputs/buttons 5, chips/pills full, avatars 50%.
- Spacing on 8pt grid; 16px side gutter on phones.

## Patterns
- Hero number: one giant value (~100px) + tiny label (temp, total, balance).
- Stat grid 2x2: small label on top, bold value below.
- List row: name left · values right · thin divider.
- Card = title · big number · mini chart. Nothing else.
- Device/toggle card: icon + name + status line; active = accent outline or fill.
- Dashboard: icon rail → section list → card grid → summary panel (phone: tabs + stacked cards).
- Onboarding: one illustration · 30px headline · one sentence · one CTA · dots.
- Login: greeting headline (35px) · 2 fields · full-width button · small text links.

## Never
More than one accent. Shadows + borders together. Over 3 font sizes per screen. Paragraphs on cards.
