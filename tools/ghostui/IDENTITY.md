Rules seen across all 33 themes:
- Dark bases are tinted (chroma .01-.15), never flat grey; text picks up a hue (luxury = gold text, coffee = warm).
- Accent is usually the lightest color (L 75-93) and used sparingly.
- Radius + border width alone flip the mood: 0/1px = serious, 2rem/2px = playful.
- Grain/noise only on paper-like recipes.

Signature ideas by subject: home → floor plan / dial · money → live chart line · music → waveform · travel → route map · food → plate/ingredient grid · fitness → rings · weather → sky that changes with data · tools → keyboard keys.
