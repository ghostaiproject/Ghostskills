# Reward map (brain reward system → app feel) · ghost 2026-11-04
Read when an app should feel satisfying / "make it fun" / habit loops. Pairs with MOTION.md (timings).

## How the brain scores a moment
- Dopamine = prediction error, not pleasure: better than expected → burst; exactly as expected → nothing; expected and missing → dip (Schultz 1997). → Same pop every time fades; a surprise that beats the guess lands.
- "Wanting" (dopamine, cue-driven pull) ≠ "liking" (the pleasure itself, opioid hot spots) (Berridge). → Cues build pull; the payoff must also feel good, or it turns into empty itch.
- Goal gradient: effort speeds up as the goal nears; free head-start stamps make people finish faster (Kivetz 2006). → Show progress, start it above 0, make the last steps loud.
- Peak-end: a moment is remembered by its peak and its end. → Spend the polish on the finish (last item, trip done), not the middle.
- Competence (self-determination theory): feeling capable beats points. → Reward real wins (money saved, food not wasted), never fake ones.

## Reward kinds (pick the ones that fit the product) · ghost 2026-11-05
Format: kind → brain → use it for → watch out.
- Surprise → dopamine prediction error → small varied wins, rare bonus lines → random loot = gambling.
- Curiosity → wanting to know lights up the caudate (reward) and boosts memory of the answer (Kang 2009, Gruber 2014) → teasers ("2 new lows today"), reveal on tap, "why?" tips, gated hints → clickbait that never pays off.
- Social approval → good reputation hits the same striatum as money (Izuma 2008) → share a win, household thanks, kudos from family → public rankings and shame.
- Giving (warm glow) → giving by choice fires reward areas more than giving because you must (Harbaugh 2007) → donate leftovers, help a friend's list, "you fed 3 people" → guilt-trip asks.
- Anticipation → dopamine rises in the caudate before a peak, then the accumbens at the peak (Salimpoor 2011, music) → build-up before the reveal (count-up, drumroll fill, ring closing) → wait so long it feels like lag.
- Effort / ownership (IKEA effect) → people value what they built, only if it works out (Norton 2012) → let users build lists, recipes, custom looks; save what they made → forced busywork, losing their work.
- Mastery / competence → feeling capable (self-determination theory) → levels of skill, tips that unlock, "you're faster than last week" → points for nothing.
- Autonomy → choice feels rewarding → options, undo, skip, own pace → nag flows.
- Completion → open loops nag, closing them feels good (Zeigarnik, classic) → checklists, sets of 5, "1 left" → endless unclosable to-dos.
- Collection → completing a set → badges, stamp cards, cooked-every-recipe map → collecting for its own sake.
- Relief → avoiding a bad outcome also teaches, through striatum avoidance circuits (mixed evidence) → "saved before it expired", "price drop caught", risk cleared → manufactured fear to sell relief.
- Sensory → touch, sound, motion, color done well (juice) → haptics, springs, confetti, soft sounds → noise, motion sickness.
- Play / humor → light surprise and jokes lower effort → playful empty states, easter eggs → jokes in serious moments.
- Rest / calm → closure and quiet are rewards too → "all done, nothing due" calm screens → hiding real alerts.

## Rules
1. Every tap answers in <100 ms: squish on press, spring back past 1 (damping ~0.35-0.5), light haptic tick.
2. Fold-outs: spring with a little overshoot (damping ~0.65-0.8), content rises in staggered 35-50 ms/row, cap ~10 rows.
3. Completion = bigger than a tap: confetti pop from the control, firm haptic, the real number floating up ("+$2.40 saved").
4. Scale the reward to the win: tap < check-off < goal done < week streak. One big moment per goal, never on every scroll.
5. Vary it a little (color mix, burst angle, rare bonus line) so prediction error stays > 0; never random money or loot.
6. Progress visible + head start: bars, "3 of 8", near-done glow on the last 20 %.
7. Endings matter: list done / trip done gets the shower + summary of what was won.
8. Missed = soft, never punishing (no red shame, no broken-streak guilt); offer Undo.
9. Ethics: no dark patterns (fake scarcity, infinite feeds, guilt pings, gambling loops). Reward the user's own goal, not screen time. Respect reduce-motion: keep haptic + text, drop particles.
10. Check on a real phone: feel > screenshot. Too much juice = noise; remove one layer if it slows a task.

## Ideas bank (pick per app)
- Streaks with freeze days · weekly recap card (peak-end) · milestone badges for real outcomes · gentle sound pack (off by default) · "beat last week" ghost bar · surprise tip after a good week · count-up numbers (roll, don't jump).
