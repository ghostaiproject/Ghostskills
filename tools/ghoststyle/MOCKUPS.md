# Tutorial mockups
One mockup per step, ≤30 chars wide, in a code block. `▶` marks what to tap; step line under it.
```
┌────────────────────────────┐
│ Settings              ⋮    │
├────────────────────────────┤
│  Account                   │
│▶ Notifications       ›     │
│  Privacy                   │
└────────────────────────────┘
 1. Tap Notifications
```
- Show only the part of the screen that matters; skip status bars.
- Toggles: `[on ●]` `[○ off]`. Buttons: `( Save )`. Fields: `[ type here__ ]`.
- More than 4 steps → one mockup per 2 steps.
